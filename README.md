# 손주팡

큰 블록과 쉬운 조작으로 즐기는 5×5 매치3 퍼즐입니다.
손주 사진을 블록으로 만들어 두면, 그 블록을 맞출 때마다 사진이 화면에 크게 뜹니다.

**[▶ 바로 하기](https://novqst47a-ux.github.io/grandchild_pang/)** — 설치 없이 브라우저에서 바로 열립니다.

## 어떤 게임인가요

같은 그림 3개를 가로나 세로로 모으면 블록이 사라지고 점수가 오릅니다. 시작할 때
**3분 도전**, **무제한**, **나무 키우기** 중 하나를 고르며, 한 번에 여러 줄이 연달아 터지면 점수가 곱절이 됩니다.

- **3분 도전** — 3분 안에 최고 점수를 냅니다. 1~3위 기록을 이 브라우저에 저장합니다
- **무제한** — 횟수와 시간 제한 없이 진행하며 순위 기록은 남기지 않습니다. 마지막 점수는
  브라우저에 저장되어 다음에 이어할 수 있습니다. 9,999점에서 계속할지 물어보고, 계속하면
  99,999점까지 올라갑니다. 그 뒤에는 `만점`으로 표시하고 계속 즐길 수 있습니다
- **나무 키우기** — 3분으로 시작해 블록을 맞추며 나무를 기릅니다. 열매 5개가 달리면 15초 동안
  계속 수확하는 피버가 시작되고, 게임의 남은 시간이 1분 늘어납니다. 이 모드의 1~3위 기록을
  브라우저에 따로 저장합니다

### 나무 키우기

컴퓨터에서는 게임판 왼쪽, 휴대폰에서는 게임판 위에 나무가 보입니다. 사라진 블록 하나마다
성장 포인트가 1점씩 쌓이며, 연쇄로 사라진 블록도 포함합니다. 연쇄 점수 배수는 성장 포인트에
적용하지 않습니다. 15점에 어린 나무, 35점에 다 자란 나무가 됩니다.

40점부터 5점마다 열매가 하나씩 달리고, 60점에 열매 5개가 모두 달립니다. **수확 피버**에
들어가면 게임의 남은 시간에 1분을 한 번 더하고 게임 타이머를 멈춥니다. 진행 중인 연쇄가
끝나면 퍼즐판 전체를 덮는 수확 화면에서 별도의 **15초 수확 시간**이 시작됩니다. 열매를 직접
누르면 하나당 게임 점수 200점을 받고, 수확한 자리에는 0.25초 뒤 새 열매가 달립니다.

15초 동안 최대한 많은 열매를 수확하세요. 피버 시간이 끝나면 수확 개수와 보너스 점수를
알려 주고 새싹부터 다시 키웁니다. 멈춰 둔 게임 타이머도 다시 흐릅니다. 이번 게임에서 수확한
열매 수는 계속 쌓이며, 게임의 남은 시간이 끝나면 종료됩니다.

블록 점수와 수확 보너스를 합친 최종 점수로 **나무 키우기 1~3위**를 기록합니다. 같은 점수라면
먼저 기록한 게임이 앞섭니다. 순위는 게임 방법을 고르는 화면과 게임 종료 화면에서 확인할 수
있으며, 3분 도전 기록과 따로 이 브라우저에 저장합니다.

열매 안에는 꾸민 사진 블록이 보입니다. 사진이 없으면 기본 블록 그림이 나타납니다.
나무와 열매는 이미지 생성으로 만든 [그래픽 리소스](webapp/assets/tree/)를 사용하며,
[생성 프롬프트와 출처](webapp/assets/tree/generation-prompts.md)를 함께 보관합니다.

어르신과 저시력자가 쓰기 편하도록 만들었습니다.

- 블록 한 칸이 최대 120px. 좁은 화면에서도 5칸이 잘리지 않게 같이 줄어듭니다
- 색이 비슷해 보여도 구분되도록 블록마다 모양 배지(해·하트·별·꽃·보석)를 달았습니다
- 맞지 않는 자리를 골라도 점수가 줄지 않습니다. 되돌릴 수 없는 조작이 없습니다
- 맞출 곳이 없으면 알아서 섞어 드립니다

## 조작 방법

### 블록 옮기기 — 두 가지 중 편한 쪽으로

| 방법 | 하는 법 |
|---|---|
| 눌러서 바꾸기 | 옮길 블록을 한 번 누르고, **바로 옆 블록**을 한 번 더 누릅니다 |
| 밀어서 바꾸기 | 블록을 누른 채 옮기고 싶은 쪽으로 밉니다 |

- 바꿀 수 있는 건 위·아래·왼쪽·오른쪽으로 **맞닿은 블록**뿐입니다.
- 3개가 모이지 않는 자리면 블록이 제자리로 돌아오고, **점수도 그대로**입니다.
- 누르고 있는 동안 블록이 1.5배로 커집니다. 어느 그림을 짚었는지 손가락 옆으로 보입니다.

### 화면의 버튼

| 버튼 | 하는 일 |
|---|---|
| 💡 힌트 보기 | 맞출 수 있는 자리를 반짝여 알려 줍니다 |
| ↻ 새 게임 | 처음부터 다시 합니다. 누르면 한 번 더 물어봅니다 |
| 🔊 소리 | 효과음을 켜고 끕니다 |
| 📳 진동 | 진동을 켜고 끕니다. 소리와 따로 켜고 끌 수 있습니다 |
| ⚙ 꾸미기 | 사진 블록을 만들고, 칭찬 연출을 고릅니다 |

### 키보드로 하기

방향키로 블록 사이를 옮겨 다니고, `Enter` 또는 `Space`로 고릅니다. 두 번 고르면 자리가 바뀝니다.

## 사진 블록 만들기

**꾸미기**를 누르면 세 걸음으로 끝납니다. 한 번에 한 가지만 물어봅니다.

1. **어떤 블록을 바꿀까요** — 해님·하트·별·꽃·보석 중에서 고릅니다
2. **사진을 골라 주세요** — 카메라로 찍거나, 앨범에서 고르거나, 샘플 그림을 씁니다
3. **사진을 맞춰 볼까요** — 끌어서 위치를, 두 손가락이나 슬라이더로 크기를 맞춥니다.
   옆으로 누운 사진은 왼쪽·오른쪽으로 돌리고 좌우로 뒤집을 수 있습니다.
   모양은 토끼·곰·고양이·별·꽃·하트·리본·동그라미·네모 아홉 가지입니다

마음에 안 들면 **그림 블록으로 되돌리기**로 언제든 되돌립니다.
**꾸민 모습 저장하기**로 파일 하나에 담아 두면 새 기기에서 그대로 불러올 수 있습니다.

## 맞췄을 때 나오는 칭찬

블록이 사라질 때마다 **좋아요! → 멋져요! → 대단해요!** 가 뜹니다. 연달아 터질수록 올라갑니다.

사진 블록을 맞추면 여기에 더해 **그 손주 사진이 화면에 크게** 뜨고, 둘레로 사진 파티클과
폭죽이 퍼집니다. 이 연출은 **꾸미기 → 더 보기**에서 끄거나 모양을 바꿀 수 있습니다.

## 홈 화면에 설치하기

주소창 없이 앱처럼 열리고, **꾸며 둔 사진이 기기에 오래 남습니다.**
브라우저 탭으로만 쓰면 저장 공간이 부족할 때 사진이 지워질 수 있습니다.

| 기기 | 하는 법 |
|---|---|
| 안드로이드 | 뜨는 팝업에서 **설치하기**. 놓쳤다면 **꾸미기 → 더 보기 → 앱으로 설치** |
| 아이폰·아이패드 | 아래 **공유 버튼(⬆)** → **홈 화면에 추가** |

한 번 설치하면 인터넷이 끊겨도 게임이 열립니다.

## 사진은 어디에 저장되나요

**고른 사진은 기기 밖으로 나가지 않습니다.** 인터넷으로 보내지 않고, 브라우저 안(IndexedDB)에만
저장합니다. 이 주소는 누구나 열 수 있지만, 올라가 있는 것은 게임 코드와 기본 블록 그림뿐입니다.
다른 사람이 여기서 내 사진을 볼 수 없습니다.

소리와 진동을 껐는지 여부는 기억해 두었다가 다음에 열 때 그대로 이어 줍니다.
3분 도전과 나무 키우기의 상위 3개 점수를 각각 저장하고, 무제한 모드의 마지막 점수도 저장합니다.
진행 중인 판과 나무의 성장·수확 상태는 저장하지 않습니다.
창을 닫으면 게임 방법을 다시 고릅니다.

## 눈과 손에 맞춰 쓰기

- 휴대폰·브라우저의 **글꼴 크기 설정**을 그대로 따릅니다
- 운영체제의 **고대비**와 **모션 줄이기** 설정을 알아서 반영합니다
- 화면 낭독기는 블록을 "3행 2열, 노란 해님"처럼 자리와 색·모양을 함께 읽어 줍니다
- 소리를 꺼도 짧은 진동으로 맞췄는지 알려 줍니다. 진동만 따로 끌 수도 있습니다

## 직접 실행해 보려면

빌드 단계가 없습니다. `webapp/` 폴더가 곧 배포본입니다.

```bash
cd webapp
npm run dev
```

`http://localhost:5173/`을 엽니다. npm 의존성은 없어 `npm install`도 필요 없습니다.
`npm test`로 테스트를, `npm run check`로 문법·색 대비 검사를 돌립니다.
`main`에 push하면 GitHub Actions가 검사를 거쳐 GitHub Pages에 올립니다.
