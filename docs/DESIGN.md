# 손주팡 디자인 시스템 (리뉴얼 v2)

> 5×5 매치3 게임 **손주팡**의 UI 구현 스펙.
> 어르신(저시력·큰 터치 필요)이 직접 플레이하고, 가족이 사진을 넣어 꾸며주는 앱.

## 0. 리뉴얼 3원칙

| 영역 | 참조 스타일 | 핵심 결정 |
|---|---|---|
| **메인 게임 영역** | 듀오링고 / 닌텐도 | 입체 블록 + 통통한 3D 버튼. 눌리는 느낌(립 shadow)이 반드시 있어야 함 |
| **꾸미기 설정 모달** | 토스 | 한 화면에 한 가지만. 플랫하고 조용한 면, 하단 고정 큰 버튼, 스텝 진행 |
| **전체 색감·톤** | 당근 | 따뜻한 크림/주황 계열. 차가운 회색·순검정 금지 |

**가장 중요한 규칙 하나:** 게임 영역은 **입체적(3D 립)**, 모달은 **평평(플랫)**.
이 대비가 "지금은 노는 화면 / 지금은 설정 화면"을 어르신에게 말없이 알려준다.

## 1. 색상 토큰

### 1.1 기본 (당근 · 따뜻한 톤)

```css
:root {
  /* 배경·면 */
  --canvas:        #fff9f3;  /* 앱 전체 배경. 순백 아님 */
  --surface:       #ffffff;  /* 카드, 모달 내부 면 */
  --surface-warm:  #fff3e9;  /* 선택된 항목, 안내 박스 */
  --line:          #eadfd2;  /* 기본 테두리 */
  --line-strong:   #d8c9b8;  /* 강조 테두리, 게임판 외곽 */

  /* 글자 */
  --ink:           #2b2621;  /* 본문·제목. 순검정(#000) 금지 */
  --ink-soft:      #6e6459;  /* 보조 설명 */
  --ink-faint:     #9c9084;  /* 비활성, 플레이스홀더 */

  /* 브랜드 */
  --carrot:        #ff6f0f;  /* 브랜드 강조: 아이콘, 진행바, 하이라이트 */
  --carrot-deep:   #c2410c;  /* 흰 글자를 얹는 채움 버튼 면 */
  --carrot-lip:    #93300a;  /* 위 버튼의 3D 립 */
  --carrot-tint:   #fff0e5;  /* 아주 옅은 브랜드 배경 */

  /* 의미 */
  --success:       #1f7a55;  --success-lip: #145c3f;  --success-tint: #e7f5ee;
  --danger:        #c42f2f;  --danger-lip:  #98211f;  --danger-tint:  #fdeeec;
  --reward:        #f2b705;  --reward-lip:  #b98204;  /* 점수·별 */
  --focus:         #1b64da;  /* 선택/포커스 링 (토스 블루 계열) */
  --focus-tint:    #e8f3ff;
}
```

### 1.2 대비 검증 (WCAG)

| 조합 | 비율 | 판정 |
|---|---:|---|
| `--ink` on `--canvas` | 14.3 : 1 | AAA |
| `--ink-soft` on `--canvas` | 5.5 : 1 | AA |
| 흰 글자 on `--carrot-deep` | 5.2 : 1 | AA |
| 흰 글자 on `--focus` | 5.4 : 1 | AA |
| 흰 글자 on `--success` | 5.3 : 1 | AA |
| 흰 글자 on `--danger` | 5.5 : 1 | AA |
| `--ink` on `--reward` | 8.2 : 1 | AAA |

**금지:** 밝은 `--carrot`(#ff6f0f) 위에 흰 글자 (2.8:1, 저시력 사용자에게 읽히지 않음).
`--carrot`은 아이콘·테두리·진행바 채움 등 **비텍스트 용도로만** 사용한다.

### 1.3 블록 색상 (게임판 전용)

5종 블록은 색 + **모양**으로 이중 구분한다. 색맹·저시력 사용자를 위해 색 하나만으로 구분되는 상태를 만들지 않는다.

| 슬롯 | 이름 | 면 | 립(darker) | 모양 힌트 |
|---|---|---|---|---|
| 1 | 딸기 | `#e2483d` | `#b32e26` | ● 원형 |
| 2 | 감귤 | `#ff8a1f` | `#c75e00` | ◆ 마름모 |
| 3 | 햇살 | `#ffc53d` | `#c98a00` | ★ 별 |
| 4 | 새싹 | `#34a06a` | `#1f7049` | ▲ 삼각 |
| 5 | 하늘 | `#3d8fe0` | `#2464a8` | ■ 사각 |

사진 블록으로 교체되면 색은 사진에 가려지지만 **립·테두리·모양 배지는 슬롯 색을 유지**한다. 그래야 손자 사진 5장이 다 비슷해도 구분이 된다.

```css
--space-1: 4px;  --space-2: 8px;  --space-3: 12px;
--space-4: 16px; --space-5: 24px; --space-6: 32px; --space-7: 48px;
```

|---|---|
| 주요 버튼 (계속/적용/새 게임) | **높이 64px** |

| 버튼 사이 간격 | **12px 이상** (오터치 방지) |

## 4. 깊이 (게임 영역 = 입체 / 모달 = 플랫)

듀오링고식 **립(lip)**: 흐릿한 그림자가 아니라, **자기 색의 어두운 톤으로 된 단색 오프셋**.

| 레벨 | 처리 | 사용처 |
|---|---|---|
| L0 플랫 | 그림자 없음 | 모달 내부 면, 본문 |
| L1 아웃라인 | `2px solid var(--line)` | 모달 카드, 목록 행 |
| L2 립 (얕음) | `0 4px 0 <darker>` | 아이콘 버튼, 칩 |
| L3 립 (기본) | `0 6px 0 <darker>` | 게임 블록, 주요 버튼 |
| L4 립 + 앰비언트 | `0 8px 0 <darker>, 0 14px 28px rgba(90,60,30,.16)` | 게임판, 결과 오버레이 카드 |

**누름 반응 (필수):**

```css
.tile:active, .btn-3d:active {
  transform: translateY(6px);
  box-shadow: none;
}
```

**모달 안에서는 립을 쓰지 않는다.** 모달의 버튼·카드는 평평하고, 구분은 테두리와 여백으로만 한다. (토스 원칙)

## 5. 메인 게임 영역 (듀오링고 / 닌텐도)

### 5.1 상단바 `.topbar`

- 배경 `--canvas`, 하단 구분선 없음(여백으로 구분).
- 브랜드 `손주팡`: Title 30px/900, 마크는 `--carrot-deep` 면 + `--carrot-lip` 립, radius 16px, 살짝(-3deg) 기울임.
- 우측 아이콘 버튼(`소리`, `꾸미기`): 56×56 이상, 흰 면 + `2px --line` + `0 4px 0 --line-strong` 립. 아이콘 26px + 라벨 15px 2줄 구성 유지(아이콘만 두지 않는다).

### 5.2 점수판 `.scoreboard`

3칸 구성 유지하되 톤 변경:

| 카드 | 면 | 립 | 글자 |
|---|---|---|---|
| 점수 `.score-card` | `--carrot-deep` | `--carrot-lip` | 흰색, 숫자 34px/900 |
| 안내 `.message-card` | `--surface` | `0 4px 0 --line-strong` | `--ink` 19px/800 |
| 남은 이동 `.moves-card` | `--reward` | `--reward-lip` | `--ink`(검정 아님) 34px/900 |

남은 이동이 **3 이하**면 `.moves-card`를 `--danger` 면 + 흰 글자로 전환하고 1회 펄스. 색만 바꾸지 말고 라벨을 `남은 이동 3번!`처럼 숫자를 문장에 포함시킨다.

### 5.3 게임판 `.board`

- 배경 `#f6e6d3` (따뜻한 나무톤), 외곽 `4px solid var(--line-strong)`, radius `--r-xl`.
- 그림자 L4. 안쪽 상단 하이라이트 `inset 0 3px rgba(255,255,255,.7)` 유지.
- 블록 간격 `clamp(6px, 1.8vw, 10px)` — 기존보다 넓혀 오터치를 줄인다.

### 5.4 블록 `.tile` — 핵심 컴포넌트

```
면      : 슬롯 색 (또는 사진)
테두리  : 3px solid rgba(255,255,255,.85)  (사진 블록 가독성 확보)
반경    : --r-lg (22px)
립      : 0 6px 0 <슬롯 립 색>
모양배지: 우상단 22px, 반투명 흰 원 + 슬롯 모양 아이콘
누름    : translateY(6px), 립 제거, 90ms
```

**상태**

| 상태 | 처리 |
|---|---|
| 선택됨 | `--focus` 4px 외곽 링 + `translateY(-6px) scale(1.05)` + "선택" 라벨 유지 |
| 힌트 | 700ms 통통 튀는 펄스 2회 (`ease-bounce`) + 아래에서 위로 살짝 점프 |
| 매치 | 1.12배 팽창 후 작아지며 사라짐 (280ms) |
| 새로 떨어짐 | 위에서 낙하 + 착지 시 살짝 눌렸다 복원 (닌텐도식 squash) |
| 잘못된 이동 | 좌우 흔들기 300ms + 짧은 저음 효과음. **에러 문구 없음** |
| 드래그 중 | 원본 28% 투명, 고스트는 1.08배 확대 + `--focus` 5px 링 |

**금지:** 흐린 drop-shadow로 입체감 대체, 블록 축소로 5×5 이상 격자 만들기, 색만으로 종류 구분.

### 5.5 큰 버튼 `.wide-button` (힌트 / 새 게임)

- 흰 면, `2px --line`, 립 `0 6px 0 --line-strong`, radius `--r-md`, 높이 **64px**.
- 아이콘 + 한글 라벨 항상 병기. 라벨은 20px/900.
- 최대 폭 280px, 가운데 정렬, 간격 12px.

### 5.6 칭찬 · 결과

- 매치 성공 시 칭찬 이미지 팝(850ms, overshoot 허용) — 이 앱에서 **bounce는 축하 순간에만** 허용.
- 게임 종료 오버레이 `.overlay-card`: 흰 면, `4px solid var(--reward)`, radius `--r-xl`, 립 L4.
  - 키커 `참 잘했어요!` `--carrot-deep` 20px/900
  - 최종 점수 Display 42px `--carrot-deep`
  - CTA `다시 시작` = 주요 3D 버튼 1개만.

## 6. 꾸미기 설정 모달 (토스)

### 6.1 구조 전환: 긴 스크롤 → 스텝

현재는 한 다이얼로그에 4개 섹션이 세로로 쌓여 있다. 이를 **한 번에 한 스텝**으로 바꾼다.

```
[1/3] 어떤 블록을 바꿀까요?     → 5개 슬롯 중 하나 선택
[2/3] 사진을 골라주세요          → 카메라 / 사진 선택 / 샘플
[3/3] 사진을 맞춰볼까요?         → 모양 선택 + 확대/위치 조절
      완료                      → "○○ 블록이 바뀌었어요" + 계속 꾸미기 / 게임으로
```

- 프리셋 저장·불러오기·전체 초기화는 스텝 흐름에서 빼서 **모달 첫 화면 하단의 "더 보기"** 안으로 이동. 매번 보일 필요가 없다.
- 각 스텝은 **질문 한 문장 + 입력 하나**. 설명은 한 줄 이내.
- 뒤로 가기는 좌상단 화살표, 닫기는 우상단 ×. 둘 다 56px.

### 6.2 모달 셸

| 항목 | 값 |
|---|---|
| 폭 | `min(100% - 20px, 640px)`, ≤560px에서는 전체 화면 시트 |
| 배경 | `--surface` (흰색. 게임 화면의 크림과 대비되어 "설정 모드"임을 알림) |
| 반경 | `--r-xl`, 전체 화면 시트일 때 상단만 28px |
| 테두리 | 없음 (플랫) |
| 백드롭 | `rgba(43,38,33,.5)` + `blur(3px)` |
| 헤더 | 높이 76px, 배경 `--surface`, 하단 경계선 없음. 제목 Title 30/900 |
| 진행 표시 | 헤더 아래 4px 바, 트랙 `--line`, 채움 `--carrot`, 폭 애니메이션 250ms |
| 본문 | 패딩 24px 20px, 세로 스크롤 |
| 푸터 | 하단 고정(sticky), 배경 `--surface`, 상단 그림자 `0 -1px 0 var(--line)`, 안전영역 패딩 포함 |

### 6.3 모달 버튼 (플랫)

| 종류 | 스타일 |
|---|---|
| 주요(다음/적용) | 면 `--carrot-deep`, 흰 글자 20px/900, radius `--r-md`, 높이 **64px**, **폭 100%**, 립 없음 |
| 주요 비활성 | 면 `#f0e9e1`, 글자 `--ink-faint`, 크기 동일(레이아웃 흔들림 방지) |
| 보조 | 면 `--surface`, 글자 `--ink`, `2px solid var(--line)`, 높이 56px |
| 옅은 강조 | 면 `--carrot-tint`, 글자 `--carrot-deep`, 테두리 없음 |
| 위험(전체 초기화) | 면 `--danger-tint`, 글자 `--danger`, `2px solid var(--danger)` |

푸터에는 **주요 버튼 한 개**만 둔다. 보조 동작은 본문 안에.

### 6.4 선택 항목 (슬롯 · 모양)

- 카드형, 최소 96×96, 간격 12px, 가로 스크롤 대신 **2~3열 그리드** 권장(가로 스크롤은 어르신에게 발견되기 어렵다).
- 기본: 면 `--surface`, `2px solid var(--line)`, radius `--r-md`.
- 선택: 면 `--focus-tint`, `3px solid var(--focus)`, 우상단 체크 원(`--focus` 면 + 흰 체크). "선택됨" 텍스트도 함께 유지.
- 선택 전환 시 150ms 페이드. 튀는 모션 없음.

### 6.5 사진 자르기 영역

- 캔버스 정사각, 폭 100%(최대 360px), `3px solid var(--line-strong)`, radius `--r-lg`.
- 안내 `두 손가락으로 크기를 바꾸거나, 아래 막대를 움직여 보세요` — 캔버스 아래 Body-S로 상시 표시(오버레이 힌트보다 읽기 쉬움).
- 슬라이더: 트랙 높이 12px, 손잡이(thumb) **36px 원**, `accent-color: var(--carrot-deep)`, 높이 48px 터치 영역.
  - 라벨과 현재 값(`사진 크기 120%`)을 항상 같이 표시.
  - 좌우에 `−` / `+` 56px 버튼을 함께 제공(드래그가 어려운 손을 위한 대체 조작).
- `위치 초기화`는 보조 버튼.

### 6.6 안내·주의 문구

- 개인정보 안내: 면 `--carrot-tint`, 좌측 5px `--carrot` 바, radius 12px, 16px 글자.
  문구 예: `사진은 이 기기에만 저장돼요. 인터넷으로 보내지 않아요.`
- 준비 중 섹션(칭찬 효과)은 스텝 흐름에서 제거하고, "더 보기" 안에 회색 카드로만 남긴다.

## 7. 보이스 & 톤 (당근 + 듀오링고)

- 어미는 `-어요 / -예요`. `-습니다` 금지. 사무적인 느낌은 거리감을 준다.
- 명령형 대신 권유형: `누르세요` → `눌러 보세요`.
- 실패를 지적하지 않는다. `잘못된 이동입니다` ✕ → `여기는 안 움직여요. 다른 곳을 눌러 보세요` ○.
- 칭찬은 짧고 구체적으로: `잘했어요!`, `3개 맞췄어요!`, `한 번 더!`
- 어려운 말 금지: 프리셋 → **꾸민 모습**, 슬롯 → **블록 자리**, 크롭 → **사진 맞추기**, 초기화 → **처음으로 되돌리기**.
- 숫자는 문장 안에 넣는다: `남은 이동 3` 보다 `이제 3번 움직일 수 있어요`.

| 상황 | 문구 |
|---|---|
| 시작 | `같은 그림 3개를 모아 보세요` |
| 힌트 | `여기를 옮겨 보세요` |
| 성공 | `잘했어요! +30점` |
| 안 움직임 | `여기는 안 움직여요` |
| 이동 소진 | `오늘은 여기까지! 참 잘했어요` |
| 적용 완료 | `할머니 사진이 블록에 들어갔어요` |
| 사진 없음 | `아직 사진이 없어요. 카메라로 찍어볼까요?` |

**금지어:** `오류가 발생했습니다`, `데이터가 없습니다`, `실패`, `잘못`, `불가능`.

## 8. 모션

| 토큰 | 값 | 용도 |
|---|---|---|
| `--m-press` | 90ms | 블록·버튼 눌림 |
| `--m-fast` | 150ms | 선택 전환, 호버 |
| `--m-base` | 250ms | 모달 스텝 전환, 진행바, 피드백 |
| `--m-slow` | 400ms | 블록 낙하, 점수 카운트업 |
| `--m-celebrate` | 850ms | 칭찬 팝, 종료 오버레이 |

| 이징 | 커브 | 용도 |
|---|---|---|
| `--e-enter` | `cubic-bezier(0, 0, .2, 1)` | 모달·시트 등장 |
| `--e-exit` | `cubic-bezier(.4, 0, 1, 1)` | 닫힘 |
| `--e-standard` | `cubic-bezier(.4, 0, .2, 1)` | 양방향 전환 |
| `--e-bounce` | `cubic-bezier(.34, 1.56, .64, 1)` | **게임 영역 전용** — 힌트, 칭찬, 점수 팝 |

**bounce 사용 규칙:** 게임판·칭찬·결과에서만. 모달 안에서는 절대 사용하지 않는다(설정 화면이 흔들리면 조작이 어려워진다).

**모달 스텝 전환:** 좌우 슬라이드 대신 **페이드 + 8px 상승**(250ms `--e-enter`). 방향 이동은 "되돌아갈 수 있나?"를 헷갈리게 한다.

`prefers-reduced-motion: reduce`에서는 모든 모션을 0.01ms로 축소하되, **누름 시 색 변화는 유지**한다. 눌렸다는 피드백까지 없애면 안 된다.

## 11. Do / Don't

**Do**

- 게임 블록·버튼에는 항상 자기 색의 어두운 톤 립을 준다.
- 주요 동작은 화면당 하나.
- 색과 함께 모양·문구를 같이 준다.
- 아이콘 옆에 한글 라벨을 붙인다.
- 배경은 따뜻한 크림, 글자는 `--ink`(순검정 아님).

**Don't**

- 밝은 주황(`--carrot`) 위에 흰 글자를 얹지 않는다.
- 모달 안에서 3D 립·bounce 모션을 쓰지 않는다.
- 어르신용 화면에서 가로 스크롤로만 접근되는 선택지를 만들지 않는다.
- 회색조 미니멀(차가운 #f5f5f5, #000) 톤으로 되돌아가지 않는다.
- 얇은 글씨(300 이하), 15px 미만 본문을 쓰지 않는다.
- 버튼을 56px 아래로 줄이지 않는다.
