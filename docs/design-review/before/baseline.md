## 재측정 방법

개발 서버를 띄운 뒤 브라우저 콘솔에서 실행한다.

```js
const g = (s, p) => getComputedStyle(document.querySelector(s))[p];
const r = (s) => document.querySelector(s).getBoundingClientRect();
({ 뷰포트: innerWidth, 본문: g('body','fontSize'), 블록: Math.round(r('.tile').width),
   블록립: g('.tile','boxShadow'), 간격: g('.board','gap'), 바닥: g('.board','backgroundColor'),
   버튼높이: Math.round(r('.wide-button').height) })
```
